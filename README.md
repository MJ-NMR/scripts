# Personal Scripts Documentation

This directory contains a collection of my personal custom shell scripts used for system management and productivity. Each script is designed to perform a specific function, such as adjusting system settings, managing notes, or interacting with the clipboard.

## Available Scripts

- **battery-warner.sh**: Warns when battery is low.
- **brightness.sh**: Adjusts screen brightness.
- **cht.sh**: Interactive cht.sh wrapper with fzf.
- **cliphist.sh**: Manages clipboard history.
- **kblayout.sh**: Switches keyboard layouts.
- **nmtui.sh**: Launches network manager UI in a floating window.
- **notes.sh**: Simple note-taking utility.
- **power-menu.sh**: Provides a power management menu.
- **rofi-dunst-manager.sh**: Manages Dunst notifications using Rofi.
- **volume.sh**: Controls system volume.
- **wal.sh**: Changes wallpaper and applies color schemes.
- **wikiman.sh**: Searches and displays man pages from the web.
